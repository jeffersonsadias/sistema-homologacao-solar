# Sistema de Homologação Solar

Sistema desenvolvido em Python para controle de processos de homologação de sistemas fotovoltaicos.

## Objetivo

Organizar clientes, projetos solares e status de homologação de forma simples e progressiva.

## Funcionalidades da Versão 1

- Cadastro de clientes
- Listagem de clientes
- Cadastro de projetos solares
- Listagem de projetos
- Atualização de status
- Resumo geral dos projetos

## Tecnologias utilizadas

- Python
- Git
- GitHub
